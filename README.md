# 기계설비 성능점검 업체 홈페이지

`dist` 폴더 안의 파일만 GitHub에 올리면 무료 홈페이지로 공개할 수 있는 정적 웹사이트입니다.

메인 화면의 `셀프견적` 버튼을 누르면 `estimate.html`로 이동합니다. 첫 단계에서는 점검 구분, 건축물 용도, 연면적 또는 세대수, 사용승인일자와 증축·개축·재축 및 대수선일자를 입력할 수 있습니다.

## 먼저 바꿀 내용

`dist/index.html`을 메모장 또는 VS Code로 열어 아래 임시 정보를 실제 정보로 바꾸세요.

- 한결기계설비: 실제 회사명
- 홍길동: 대표자명
- 031-000-0000: 회사 전화번호
- contact@example.com: 이메일
- 경기도 안산시 ○○구 ○○로 00: 주소
- 경기 제00-000호: 기계설비성능점검업 등록번호
- 사업자등록번호 000-00-00000: 실제 사업자등록번호

## GitHub Pages 공개 요약

1. GitHub에서 새 저장소를 만듭니다.
2. `dist` 폴더 안의 모든 파일과 `assets` 폴더를 저장소 최상단에 올립니다.
3. 저장소의 Settings → Pages로 이동합니다.
4. Source는 `Deploy from a branch`, Branch는 `main`, 폴더는 `/(root)`를 선택하고 Save를 누릅니다.
5. 수 분 뒤 `https://아이디.github.io/저장소이름/` 주소로 접속합니다.

상세 설명은 대화에서 제공된 안내를 참고하세요.
